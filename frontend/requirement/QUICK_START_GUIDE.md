# TravelMind Requirements Quick Start

## 1. Purpose

Use this folder to understand what the current frontend is supposed to do.

## 2. Main Document

The primary requirement document is:

- `PROJECT_PAGE_REQUIREMENTS.md`

## 3. How To Use It

1. Open the page you want to work on under `frontend/`.
2. Find the matching numbered section in `PROJECT_PAGE_REQUIREMENTS.md`.
3. Use `COMPONENT_STRUCTURE.md` for file mapping.
4. Update the requirement document if the page behavior changes.
